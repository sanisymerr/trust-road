## Сайт и запуск

Основная витрина — оформленный автономный HTML: `dashboard/index.html`. Онлайн-версию обслуживает `serve.py`, небольшой сервер на стандартной библиотеке Python. Данные, графики, русская локализация, выбор годов и вращающийся глобус включены в страницу; внешние библиотеки при открытии не загружаются. Основная публикация использует этот же дизайн.

Для локального запуска Python 3.12:

```bash
python serve.py
```

Откройте `http://localhost:10000`. Для другого порта задайте переменную `PORT`. Настройки существующего сервиса Trust Road описаны в `RENDER.md`; `run.sh` запускает тот же сервер. Опубликованный сайт: [trust-road.onrender.com](https://trust-road.onrender.com/). Для версии `919b381` 8 октября 2026 года подтверждены публичный ответ HTTP 200, исправный health check и совпадение SHA-256 опубликованного HTML с локальным файлом. Подробности — в `report/Проверка_запуска.md`.

## Альтернативное приложение Streamlit

`app.py` сохраняет отдельную реализацию анализа на Streamlit. Чтобы открыть её, установите зависимости из `requirements.txt` в виртуальное окружение и выполните:

```bash
python -m streamlit run app.py
```

Серверу основного сайта эти зависимости не требуются. Notebook и подготовка данных используют полный список зависимостей.

## Как пользоваться фильтрами

Национальная динамика ограничивается диапазоном лет и выбором показателя. Для регионов доступны 2015, 2019 и 2021 годы; если диапазон не содержит ни одного из них, выводится сообщение об отсутствии наблюдений. Округ ограничивает региональную выборку. В HTML клик по столбцу рейтинга, точке диаграммы или строке таблицы добавляет территорию в сравнение. В Streamlit выбор точек диаграммы обновляет связанную таблицу и график. Кнопки скачивания выгружают соответствующие данные.

В HTML есть поиск территорий, отдельные кнопки выбранных регионов, карточки их значений и места в России и выбранном округе. Можно выбрать до пяти территорий для читаемого сравнения. Рейтинг зависит от выбранного года и округа; равным значениям присваивается одинаковое место. Выбор сравниваемых территорий не меняет полный рейтинг внутри выбранного округа. Быстрые кнопки задают периоды до пандемии, 2019–2021 и после 2021 года. Режим презентации скрывает фильтры; срез сохраняется в адресе страницы. На телефоне фильтры по умолчанию свернуты. Текст итоговых выводов относится ко всей закреплённой выборке; карточки и графики отражают действующие фильтры.

## Данные и ограничения

Россия: 2015–2024. В региональном сравнении 85 неперекрывающихся территорий и восемь округов. Архангельская область показана без Ненецкого АО, Тюменская — без ХМАО и ЯНАО; округа представлены отдельно. ОПЖ страны и округов взята из официальных агрегированных рядов, а не из среднего по территориям.

Итоговая длинная таблица: 399 строк, 393 заполненных значения и шесть пропусков. Нет ОПЖ мужчин и женщин за 2024 год, числа материнских смертей за 2024 год и коэффициента смертности детей до пяти лет за 2017 и 2024 годы; отсутствует также расчётный гендерный разрыв за 2024. Значения не выдумывались и не интерполировались. Линии соединяют соседние доступные наблюдения через пропуски (`connectgaps: true`); точки обозначают только реальные значения. Мини-графики и иллюстрации notebook следуют тому же правилу, сохраняя фактические годы. Пропуски в данных и CSV остаются пропусками.

Для ОПЖ используется единая версия ЕМИСС 31293. Исторические значения округов выбраны по современным кодам 040, 041, 042. С 2022 года национальные данные в использованных источниках приведены без четырёх новых субъектов. Пометки предварительности относятся к конкретным сохранённым публикациям; младенческая смертность 2024 в использованном сборнике 2025 года уже не помечена предварительной.

Материнская смертность — прямой индикатор 3.1.1, смертность до пяти лет — 3.2.1. Младенческая смертность относится к первому году жизни и не подменяет неонатальную 3.2.2. Общая смертность и естественный прирост используются как демографический контекст. Корреляция описывает связь, а условный расчёт до 78 лет не является прогнозом.

Снимок источников проверен 7 октября 2026 года. Первичные ссылки, версии и статусы находятся в реестре. Большие PDF доступны по официальным ссылкам; в папке сохранены нужные извлечения страниц и контрольные суммы оригиналов.

### Обновление интерфейса

Годы выбираются в сетке, округа — в меню с полными названиями. Доступны клавиатура, отмена выбора и видимый применённый срез. Глобус можно вращать перетаскиванием мышью. Наведение останавливает автоматическое движение, уход указателя возобновляет его; при перетаскивании автоматическое вращение приостановлено. При системном уменьшении движения, скрытой вкладке или уходе обложки за экран автоматические кадры прекращаются. При отсутствии Canvas или ошибке рисования остаётся статичный SVG. Локальные исходники выбора — `dashboard/controls.js` и `controls.css`, движения — `dashboard/globe-motion.js` и `globe-motion.css`; они встраиваются при сборке.

Автоматические проверки охватили 17 сценариев жизненного цикла глобуса, 495 сочетаний диапазона и округа (55 диапазонов × 9 вариантов охвата), все 64 подмножества шести показателей и 954 выгрузки CSV. Это проверки реального кода в изолированной среде; работа опубликованной страницы и мобильная компоновка проверены отдельно в браузере. Критерии — в `report/UX_аудит_и_доработка.md`, результаты — в `report/Проверка_запуска.md`.
