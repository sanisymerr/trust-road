# Проверка соответствия заданию

Авторы: Зейда А.В., Капустник К.А. · ББИ-24-БА1.

| Требование | Реализация |
|---|---|
| Одна ЦУР | ЦУР 3 «Хорошее здоровье и благополучие» |
| Официальные проверяемые данные | Первичные Росстат/ЕМИСС; сохранённые XLS/XLSX, ссылки, версии и сверка значений |
| Не менее пяти лет | Ежегодные данные России за 2015–2024 |
| Россия и региональная дезагрегация | РФ обязательно; 85 территорий сравнения и восемь округов в трёх срезах |
| Не менее 3–5 показателей в рамках цели | Шесть основных показателей, с явным разделением прямых индикаторов и демографического контекста |
| Очистка, пропуски и дубликаты | Единые годы и числа, NaN, контроль составного ключа; нет заполнения выдуманными значениями |
| Производные показатели | Изменения, темпы, индекс, гендерный разрыв, отклонения и рейтинг |
| Проверка качества | Контроль баланса событий, материнского коэффициента, версии ОПЖ, ключей и диапазонов; IQR-флаги сохраняются |
| Подготовленный CSV/XLSX | CSV: `russia.csv`, `regions.csv`, `long.csv`, `validation.csv` |
| Полный Data Story | Введение, методология, национальная динамика, региональные сравнения, выводы и источники |
| Фильтры лет, территорий, показателей | HTML и Streamlit; для недоступных периодов есть сообщения |
| Кросс-фильтрация | Выбор территории на графике обновляет связанное сравнение и выделение |
| Публикация | [Опубликовано на Render](https://trust-road.onrender.com/); проверены открытие без входа, фильтры и мобильное отображение |

Локальный автономный HTML позволяет демонстрировать работу без интернета. Публичная онлайн-версия проверена 7 октября 2026 года; ссылка включена в отчёт.
