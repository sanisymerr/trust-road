# Критическая проверка и доработка дашборда

Зейда А.В., Капустник К.А. · ББИ-24-БА1

Проверка касалась достоверности значений, согласованности фильтров, сравнения территорий, клавиатуры и мобильного экрана. Финальное описание соответствует опубликованному интерфейсу `919b381`.

| Недочёт | Исправление |
|---|---|
| Карточки не следовали выбранным показателям | Показываются выбранные метрики, единицы и фактический год |
| Пропуски и пустые срезы были неочевидны | Для отсутствующих наблюдений дано пояснение; нули и придуманные значения не подставляются |
| Обратные границы периода оставляли старые расчёты | Границы согласуются; подписи, карточки, графики и ссылка обновляются вместе |
| Служебный код РФ мог попасть в список округов | Допустимы восемь округов; весь набор доступен отдельным вариантом |
| Выбор через Ctrl/⌘ неудобен на телефоне | Поиск, флажки, кнопки удаления и лимит пяти территорий |
| Выбранный регион мог не попасть в крайние столбцы | Карточка показывает значение, отклонение от РФ и место в России и округе |
| Не хватало таблицы национальных значений | Добавлена таблица выбранных показателей с единицами и явными пропусками; предварительность сохранена в исходных данных и CSV |
| Разнородные меню затрудняли выбор | Годы показаны в сетке, округа — с полными именами; поддержаны клавиатура и отмена |
| Параметры ссылки могли содержать дубли и недопустимые коды | Параметры проверяются; неверные значения заменяются допустимым исходным состоянием |
| Мобильный экран перегружался | Фильтры по умолчанию свернуты; проверены 320 и 390 px без горизонтальной прокрутки |
| Требовалось управление глобусом | Прямое вращение перетаскиванием мышью; наведение останавливает автоматическое движение, уход указателя возобновляет его |
| Разрывы затрудняли чтение линий | Доступные значения соединяются через пропуски; точки есть только у реальных наблюдений |

Оформление объединяет тёмно-синюю обложку, бирюзовый акцент ЦУР 3, российский триколор и глобус с береговыми линиями Natural Earth. Глобус служит оформлением. Его автоматическое вращение приостанавливается при перетаскивании, системном уменьшении движения, скрытой вкладке и выходе за экран. Сбой Canvas оставляет статичный SVG.

Быстрые периоды, видимый применённый срез, режим презентации и ссылка с фильтрами работают в автономном HTML и опубликованной версии. Сервер использует gzip. В Plotly для линий задано `connectgaps: true`; мини-графики и notebook также соединяют соседние доступные точки по фактическим годам. Данные и CSV сохраняют пропуски; интерполяция значений не выполняется.

Автоматическая проверка: 17 сценариев жизненного цикла глобуса, 495 сочетаний диапазона и округа, 64 подмножества показателей, 954 выгрузки CSV. Проверки кода и отдельные проверки настоящей страницы описаны в `Проверка_запуска.md`; критерии оценки — в `UX_аудит_и_доработка.md`.
