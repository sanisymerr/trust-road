В этой сессии действующий сайт не заменялся. Приведённый адрес относится к прежнему проекту и станет ссылкой на дашборд только после успешной загрузки. До этого пункт ТЗ об опубликованной онлайн-версии остаётся открытым.

## Что загрузить

Сохраните отдельную копию прежнего проекта. Загрузите **содержимое** папки `ЦУР3_Зейда_Капустник_ББИ-24-БА1` в корень подключённого репозитория `trust-road`. Файлы `app.py`, `run.sh`, `requirements-render.txt` и папка `data` должны лежать на одном уровне, без дополнительной внешней папки. Содержимое `report` и notebook можно оставить в репозитории для воспроизводимости работы.

В комплекте есть новый `run.sh`: он запускает сервер оформленного HTML на порту Render. Start Command меняется на `bash run.sh`. Старый сервер, страницы конвертера и его планировщик валют для этого проекта не используются.

## Настройки существующего сервиса

Откройте Settings сервиса Trust Road и задайте:

| Поле | Значение |
|---|---|
| Build Command | `python -m compileall -q serve.py` |
| Start Command | `bash run.sh` |
| Health Check Path | `/_stcore/health` |
| Python | Переменная `PYTHON_VERSION=3.12.14` |
| Root Directory | Пустое поле, если содержимое комплекта загружено в корень репозитория |

Команды сверены в действующем сервисе: прежняя сборка `pip install -r requirements.txt`, запуск `gunicorn --bind 0.0.0.0:$PORT app:app`, health check `/health`. Для оформленного дашборда используются значения таблицы. `serve.py` работает на стандартной библиотеке Python; дополнительные серверные зависимости не нужны. Файл `.python-version` также задаёт Python 3.12, но ранее заданная переменная `PYTHON_VERSION` имеет приоритет; проверьте её значение.

После обновления репозитория выберите **Manual Deploy → Deploy latest commit**. Для того же сервиса адрес сохранится. `render.yaml` описывает создание отдельного сервиса через Blueprint; он приложен как альтернативная конфигурация и сам по себе не обновляет настройки существующего Trust Road.

## Проверка после публикации

1. Откройте адрес сайта и убедитесь, что вместо конвертера появился дашборд ЦУР 3.
2. Стартовый экран содержит Зейду А.В., Капустника К.А. и группу ББИ-24-БА1.
3. В региональных данных за 2021 год Россия — 70,15 года; Приморский край — 68,53.
4. В периоде 2022–2024 региональный раздел сообщает об отсутствии опорных лет.
5. Проверьте, что ссылка открывается без входа в Render и доступна преподавателю.

После успешной проверки добавьте фактическую ссылку в раздел 5 отчёта и отметьте публикацию в `report/Соответствие_ТЗ.md`. До проверки прежний адрес нельзя выдавать за опубликованный дашборд.

## Автономная версия

Файл `dashboard/index.html` содержит данные и графики внутри и открывается без установки Python. Его можно использовать для локальной демонстрации; он не заменяет требуемую преподавателем онлайн-ссылку.

Официальные инструкции: [Python на Render](https://render.com/docs/python-version), [публикация сервиса](https://render.com/docs/deploys), [PORT](https://render.com/docs/environment-variables), [запуск Streamlit в сети](https://docs.streamlit.io/deploy/tutorials/docker).
